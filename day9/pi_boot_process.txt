Imager - Raspberry Pi Imager

Board - RPI 4B
OS    - Bookworm Legacy 32 bit OS

In Image, Edit settings

Select SSID & Password
[To take over the Wifi]

After Flashing

In BOOTFS
1. Edit cmdline.txt : Remove "quiet"
2. In config.txt -> Add "enable_uart=1"
3. Create an empty file -> "touch ssh"
4. Create wpa_supplicant.conf 
'''
country=IN
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1

network={
    ssid="POCO X4 Pro 5G"
    psk="STM32STM32"
}

'''
change ssid and psk according to the wifi over which you want to function host and client

NOTE: Both rpi and system should be on the same network
